# 一句话

74 站。出货是脚本，不进 Kanban。Kanban 只抓还得看页面的 5 个 Camoufox 站。没有 Verifier，没有 Synthesizer。

```
04:00  no_agent  ~/.hermes/scripts/music-daily-recs.py
         RSS 50 → HTML 17 → merge → 评分 → 报告 → git push
         末尾 spawn 5 个 Camoufox worker（失败不挡出货）

04:00–07:00  Boomkat / PoD / Wild City / JazzTokyo / musicircus
         能抓到就写 {site}_reviews.json
         0 条 / CF / 进程死 → 写空 JSON + kanban_complete

07:00  no_agent  ~/.hermes/scripts/music-daily-recs-watchdog.py
         报告不在 origin/main → 再跑管道
         尾巴 JSON 后到了 → 再 merge 补 push
         顺手清 music 看板：卡死 complete，其余 archive
         没事做 → stdout 空，不投递
```

# 时间窗口

全部 `--days 1.5`（36 小时）。禁止自算 cutoff、RSS 通了还开浏览器交叉验证、翻超过前 2 页。

# Camoufox worker

body 在 `bin/kanban-swarm.py:build_scraper_body()`，不在本文件。硬约束：

- 36h，前 2 页
- **空结果协议**：0 条 / CF / paywall → 写 `{meta, items:[]}` → `kanban_complete` → 停。禁止 `kanban_block`
- Boomkat CF 后早退，禁止反复开 tab
- `max_runtime_seconds=1200`。超时会被 dispatcher 杀掉再试，然后 block；**出货不等它**
- JazzTokyo 月刊 0 条是正常结果
